## Validation procedure
1. Open https://validator.w3.org/ and choose the **Validate by File Upload** tab.
2. Click **Choose File**, select one of the five pages above, then click **Check**.
3. Read the result banner. The goal is **Errors: 0**. Warnings (for example, a suggestion about a `role` attribute) are not
   syntax errors, but read them and fix any that point to a real problem.
4. Record the counts in the table above, and take a screenshot of the result page for each file.
5. If an error is reported, fix it in the source file, save, and re-upload until it reports no errors.

Alternative: serve the site with `npm run serve`, paste each file's source into the **Validate by Direct Input** tab.
